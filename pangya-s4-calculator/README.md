# PangYa S4 Calculator

Calculadora web experimental para PangYa Season 4.

## Perfil padrão
- 1W: 270y
- 2W: 250y
- 3W: 230y

## Recursos
- Motor de cálculo PangYaC/Acrisio
- Tomahawk, Dunk, Spike e Cobra
- Power Shot
- altura, vento, terreno, spin, curva e slope
- conversão de desvio/Smart do motor original
- upload de screenshot com OCR local
- medição de ângulo da seta do vento por dois cliques no print

## Privacidade do print
O OCR é executado no navegador com Tesseract.js. A imagem não é enviada ao servidor deste projeto.

## Créditos
O arquivo `public/engine.js` deriva do motor open-source do projeto PangYaC, que credita a lógica original a Acrisio / SuperSS Dev.
